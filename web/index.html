Strategy AI Toolkit

Working demos of how AI can support winning, researching and reporting on outcomes-based strategy work. Each tool shows its working, so a consultant can check every result before it is used.

Built by Deeksha Gulati using public documents and illustrative sample data only. Source code: see the GitHub repository linked in the README.

Tender Fit Checker

Before a bid goes in: AI lists the tender's mandatory requirements and weighted award criteria, then rates how well the draft response addresses each one, quoting the draft as evidence. Gaps are ranked by the marks at risk.

What the code checks: every evidence quote must appear word for word in the draft, or the rating is not trusted; every weight must appear in the tender; weights must add up to 100%. What the bid manager still checks: every rating, and whether each fix is true of the firm.

Both boxes hold a fictional example: a request for tender and a deliberately incomplete draft. Paste your own to try it.

Consultation Analyser

Groups free-text stakeholder responses into themes, counts how often each comes up, and pulls an example quote. The page then checks every quote word for word against the original response, so nothing invented gets through.

What the consultant still checks: every theme, the responses filed under it, and the less common points flagged at the end, which AI tends to underweight.

Document Assistant

Answers questions from a document library and cites the passage behind every point. First it searches the library for the most relevant passages; then AI answers using only those. This is the same approach a private assistant would use on a firm's own past reports.

What the consultant still checks: that each cited passage really supports the point. Citations to passages that were not retrieved are flagged in red.

Library: plain-English notes on HIQA's Corporate Plan 2025–2027 (public document), summarised passage by passage with page numbers. You can add your own text below.

Strategy Starter

For organisations that cannot fund a full strategy engagement. They describe their situation; AI drafts an outcome strategy outline with indicators and a first 90 days, which a consultant reviews in one short workshop before handover.

What the consultant still checks: whether the outcomes are the right ones, whether the indicators can really be measured, and the points the draft flags as needing expert input.

The form is filled with a fictional example. Edit it to try your own.

Everything AI produces here is a first draft. In real client work, client information would only be processed in a private, secure environment, never a free public AI tool, and a consultant reviews every output. When this page runs AI, it uses the viewer's own Claude account.
